# Campus Cafeteria POS

A Vue 3 and Vite point-of-sale prototype for the IT 415 Campus Cafeteria scenario. It supports the required cash transaction flow from menu selection through a digital receipt and a cleared new transaction.

## Run locally

1. Install [Node.js](https://nodejs.org/).
2. From the project folder, run `npm install`.
3. Run `npm run dev` and open the local address shown in the terminal.

## Features

- Six fixed menu items priced in Philippine pesos.
- Cart quantity controls, item removal, line subtotals, and order total.
- Cash validation, change calculation, payment confirmation, and receipt with transaction reference.
- Starting a new transaction clears the previous sale.
